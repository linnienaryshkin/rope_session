## Consent Frameworks

### SSC — Safe, Sane, and Consensual

All activities must be physically safe, mentally competent, and explicitly agreed upon. The dominant community standard for structured BDSM education.

### RACK — Risk-Aware Consensual Kink

Shifts emphasis to individual responsibility: participants acknowledge and accept specific risks rather than asserting blanket "safety." More realistic for activities like suspension or breath play where some risk is inherent and unavoidable.

### Ongoing Consent

Consent is not a one-time checkbox. It is continuously checked throughout a session via safewords, body language monitoring, and verbal check-ins. A rigger's responsibility is to hold the negotiated boundary even if the bottom requests otherwise during an altered state (subspace).

## Limit Taxonomy

| Term | Definition |
| ------ | ------------ |
| **Hard Limit** | Absolute no. Not negotiable, not explored. Examples: blood play, scat, age play. |
| **Soft Limit** | Hesitant or conditional interest. Open to discussion or specific context. Examples: public play, knife sensation play. |
| **Curiosity** | No experience, want to explore, need more information. |
| **Green** | Enthusiastically desired. |
| **Whitelist** | Only what is explicitly listed is permitted (conservative default for new clients). |
| **Blacklist** | Everything is permitted except what is listed (used with established trust). |

## Communication & Safeword Systems

### Traffic Light (Standard)

- **Green** — continue, more, enjoying it
- **Yellow** — pause, check in, reduce intensity
- **Red** — full stop, end the scene

### Non-Verbal Signals (for gagged/restricted bottoms)

- Object drop (holding something that falls when dropped)
- Tap pattern (3 taps = yellow, 5 taps = red)
- Squeeze signal

### Check-In Vocabulary (physical sensations to monitor)

- **Numbness** — nerve or blood compression, urgent
- **Tingling / Pins and Needles** — early nerve warning
- **Burning** — rope friction or nerve stress
- **Chilling** — circulation loss, especially in suspended limbs

## Key Concepts Glossary

| Term | Definition |
| ------ | ------------ |
| **Rigger / Top** | Person who applies rope |
| **Bottom / Bunny** | Person who receives rope |
| **Subspace** | Altered mental state during intense sensation or power exchange; reduced capacity to consent or communicate accurately |
| **Drop (sub drop / top drop)** | Post-session emotional crash, typically 12–72 hours later; why aftercare and debriefing matter |
| **Semenawa (責め縄)** | Torment rope — tight, intense, deliberately uncomfortable; a style/intent |
| **Aibunawa (愛撫繩)** | Caress rope — slow, sensual, intimate |
| **Shūchinawa (羞恥縄)** | Shame/embarrassment rope — exposure and vulnerability as central element |
| **Tsuri (吊り)** | Suspension |
| **Yuka (床)** | Floor work |
| **Ichinawa (壱縄)** | Single-rope work |
| **Takate Kote (TK)** | Standard chest harness with arms behind back — high nerve risk at radial nerve |
| **Futomomo** | Thigh tie — compresses femoral nerve |
| **Predicament bondage** | Ties designed so movement causes discomfort — tension-based |
| **RAC / RACK** | Risk Aware Consent / Risk-Aware Consensual Kink |
| **SSC** | Safe, Sane, Consensual |
| **Hard point** | Structural anchor used for suspension |
| **Radial nerve** | Most commonly compressed nerve in upper-body rope ties; causes wrist drop if damaged |
| **Femoral nerve** | At risk in Futomomo and compression of inner thigh |
| **Paresthesia** | Abnormal sensation — tingling, numbness — symptom of nerve compression |
| **Ischemia** | Insufficient blood supply — symptom of vascular compression |

## What This App Is Not

Cross-referencing against sources to be explicit about scope:

- **Not a D/s relationship contract** — ongoing submission rules, financial control, grooming requirements, daily reporting are all out of scope
- **Not a general kink checklist** — bodily fluids, permanent marking, age play, bestiality and similar are outside the session scope and should not appear
- **Not a therapy tool** — the self-reflection and conflict resolution worksheets are valuable references but personal tools for ongoing relationships, not pre-session forms
- **Not a medical consent form** — we document known conditions and risk acknowledgment, but this is not a clinical document and does not replace professional medical advice
